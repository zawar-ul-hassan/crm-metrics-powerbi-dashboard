I built this CRM Metrics & Conversion Analysis dashboard to understand how deals move through the sales pipeline and where the real performance patterns hide. As I explored the data, I wanted to answer one simple question: How healthy is our pipeline, really?

So I started breaking everything down — total deals, win/loss distribution, deal value, engagement levels, and even how long it takes to close a deal. Every metric you see in the dashboard comes from careful data modeling, DAX calculations, and a clean visual structure designed to make insights obvious at a glance.

With dynamic filters for representatives, managers, products, and locations, the dashboard becomes a fully interactive tool. I can instantly switch perspectives and see how each team or product is performing. The percentage breakdown of Won, Lost, Engaging, and Prospecting deals tells the story of conversion efficiency, while KPIs like average deal value and sales cycle duration reveal deeper operational trends.

This project reflects my approach as a data analyst: take raw CRM data, clean it, model it, and turn it into a narrative that helps decision‑makers understand what’s working — and what needs attention. It’s not just a dashboard; it’s a complete performance story built through data.
